Deadlock VO Recorder

Record replacement voice lines for a Deadlock voice pack.

Point it at your Deadlock install

Nothing is uploaded anywhere. The app reads the game's voice lines straight off your disk so you can hear the original before recording your take.

  1. Click below and select your Deadlock folder — the one containing game. In Steam: right-click Deadlock → Manage → Browse local files.
  2. Your browser will ask permission to read the folder. Allow it.
  3. Choose a folder for your recordings. Each take is written there the moment you stop recording.
  4. Pick a character, listen, record. Each line has a time limit — the original's own length — shown as the width of the wave display; recording stops there. A take that ran longer would be silent in game.
  5. When you're done, zip that folder and send it back.
Chrome or Edge recommended. Firefox works, but exporting is a single download instead of writing to a folder.

Where should takes be saved?

Pick a folder for your recordings — an empty one is easiest. Every take is written there as a .wav as soon as you stop recording, so nothing is lost if the browser closes. Reopen the same folder later and your recordings are still listed, ready to play back or redo.

The browser will ask permission to save to it. Allow it.

Microphone

Recording uses your mic with browser processing (noise suppression, auto gain, echo cancellation) switched off, so takes stay raw. Grant access when prompted.
